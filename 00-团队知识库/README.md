# 团队共享知识库

这是全项目共用的知识库，统一沉淀问答、规范、模板与方法论，避免每个项目重复维护。

## 使用原则

- 跨项目复用内容放这里，项目私有内容放各项目 `docs/`。
- 新问题优先查 `INDEX.md` 与 `FAQ/`。
- 高价值问答必须结构化沉淀，并补充适用边界。

## 目录说明

- `INDEX.md`：知识总索引
- `FAQ/`：常见问题与标准答案
- `Playbooks/`：实践手册与方法论
- `Standards/`：规范与口径定义
- `Decisions/`：跨项目决策记录
- `Templates/`：通用模板库
- `Logs/`：每周复盘与学习记录
