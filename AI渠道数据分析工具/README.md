# AI 渠道数据分析工具

这个仓库用于沉淀「产品 + 研发 + AI」共同维护的文档与规则，目标是让新需求落地更快、沟通成本更低、经验可复用。

## 协作原则

- 单一事实源：以本仓库 Markdown 为准。
- 小步迭代：每次只改一个明确主题，便于评审。
- 可追溯：每次变更都记录原因、假设、验收标准。
- AI 友好：使用统一模板与固定字段，便于检索和复用。

## 目录说明

- `docs/README.md`：文档总入口
- `docs/requirements/`：需求文档（PRD）与验收标准
- `docs/playbook/`：渠道投放经验与打法
- `docs/decisions/`：关键决策记录（ADR）
- `../00-团队知识库/`：仓库级共享知识库（跨项目复用）

## 建议工作流

1. 新需求：从 `docs/requirements/TEMPLATE.md` 复制一份开始写。
2. 复盘经验：按 `docs/playbook/TEMPLATE.md` 新建案例。
3. 关键方案：在 `docs/decisions/` 新增一条决策记录。
4. 提交变更：通过 Git 提交，保留版本历史。

## 首批待办

- 建立统一指标口径（CPA、ROAS、归因窗口等）。
- 补齐前 10 条高价值规则（条件-动作-风险）。
- 沉淀前 10 个历史案例（场景-判断-结果）。
