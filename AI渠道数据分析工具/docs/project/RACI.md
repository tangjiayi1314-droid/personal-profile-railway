# 项目协作 RACI（渠道AI数据分析平台）

## 角色定义

- 产品（PM）
- 研发（前端/后端/数据）
- 设计（UX/UI）
- 测试（QA）
- 投放负责人（渠道业务）

## 关键活动与职责

| 活动 | PM | 研发 | 设计 | QA | 投放负责人 |
|---|---|---|---|---|---|
| 需求定义与优先级 | A/R | C | C | C | C |
| 技术方案评审 | C | A/R | C | C | I |
| 交互与视觉评审 | C | C | A/R | C | I |
| 测试计划制定 | C | C | I | A/R | I |
| 规则与案例沉淀 | C | C | I | I | A/R |
| 上线审批与值班 | A | R | I | R | C |
| 周复盘与策略迭代 | A | C | I | C | R |

说明：
- R = Responsible（执行）
- A = Accountable（最终负责）
- C = Consulted（协作咨询）
- I = Informed（知会）
